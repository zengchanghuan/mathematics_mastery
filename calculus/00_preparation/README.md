- 三角函数特殊值：曾两次把 `cos(pi)` 写成 `0`，需要继续区分 `cos(pi/2)`、`cos(pi)` 和 `sin(pi)`。
- 证明书写：能够找到正确方向，但容易只做恒等变形，没有明确说明因数正负、严格不等号和“某个整数”的来源。

### 典型错因

#### 概念混淆

- 把平均变化率当作某一点的导数。
- 把圆或 `y^2 = x` 误判为函数，忽略“一个输入不能对应多个输出”。
- 把 `cos(pi)` 与 `cos(pi/2)` 或 `sin(pi)` 混淆。

#### 边界条件遗漏

- 根号内要求非负，但根号位于分母时必须严格大于零。
- 使用 `≤`、`≥` 时区间应包含有限端点；无穷端点始终使用圆括号。
- 绝对值不等式中，曾混淆中心、半径以及“取中间/取两边”。

#### 证明链不完整

- 恒等式只能完成代数变形，不能替代对正负和整数性的说明。
- 证明偶数的平方仍为偶数时，已写出 `n^2 = (2k)^2 = 4k^2`，但需要继续写成 `2(2k^2)`，并说明 `2k^2` 是整数。
