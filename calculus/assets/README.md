## 资源约定

- 优先使用 SVG；需要照片或手写记录时使用 PNG/JPG。
- Mermaid 源码优先直接保存在相应 Markdown 中。
- Markdown 必须使用相对路径，不能写本机 `/Users/...` 绝对路径。
- 新增图片后，应在对应课程文件和本索引中同时登记。
- 外部交互图若不能随 Git 同步，必须补充静态 SVG 或 PNG。
