# 当前错题与待复测队列

更新日期：2026-08-20

## 1. 下界与最小值

- 触发题：\(b_n=2+1/n\)。
- 原回答：把下界 \(2\) 判断为最小值。
- 类型：`Conceptual Error`。
- 订正：所有项都满足 \(b_n>2\)，没有任何一项等于 \(2\)；所以 \(2\) 是下界，但不是最小值。
- 当堂证据：能够正确判断 \(1/n\) 的 \(0\) 是“下界非最小值”。
- 状态：`Developing`，需要跨日无提示复测。

## 2. 保号性的“最终”限定

- 触发结论：\(a_n\to-3\)。
- 原回答：“一直为负”。
- 类型：`Conceptual Precision Error`。
- 订正：只能推出“从某一项开始一直为负”；前面有限项允许为正。
- 例子：\(a_n=-3+10/n\) 的前几项为正，之后为负。
- 状态：`Developing`。

## 3. 夹逼定理中上界与上界的极限

- 触发题：\(\lim |\sin n|/n\)。
- 原回答：\(1\)。
- 类型：`Limit Error`。
- 订正：\(0\le |\sin n|/n\le1/n\)，左右两边都趋近于 \(0\)，所以中间极限为 \(0\)。
- 当堂证据：能够补出
  \(1/n\le(2+\sin n)/n\le3/n\)。
- 状态：`Developing`，需要独立变式复测。

## 4. 运算符抄读

- 触发题：两个收敛数列因子的乘积极限。
- 原回答：把括号间乘号看成加号，得到 \(3\) 而不是乘积结果。
- 类型：`Transcription Error`。
- 订正策略：计算前先圈出最外层运算符，再分别写出每个因子的极限。
- 当堂证据：独立完成下一道乘积极限并得到 \(12\)。
- 状态：保留轻量抽查，不视为概念不会。

## 6. 特殊角正弦值取倒数

- 触发题：将 \(\sin(x+60^\circ)\) 展开并代入特殊角值。
- 原回答：\(\tfrac12\sin x+\tfrac{2}{\sqrt3}\cos x\)。
- 类型：`Special-angle Value Error`。
- 错误位置：公式展开和 \(\cos60^\circ=1/2\) 都正确，只把
  \(\sin60^\circ\) 写成了其倒数 \(2/\sqrt3\)。
- 最小提示：正弦是单位圆纵坐标，必在 \([-1,1]\) 内，而
  \(2/\sqrt3>1\)，所以不可能是 \(\sin60^\circ\)。
- 当堂订正：根据范围提示正确改为 \(\sin60^\circ=\sqrt3/2\)，并得到
  \(\tfrac12\sin x+\tfrac{\sqrt3}{2}\cos x\)。
- 状态：`Developing`，等待后续变式复测。

## 7. 正弦倍角代入后的分子漏算

- 触发题：第二象限中 \(\sin a=3/5\)、\(\cos a=-4/5\)，求 \(\sin2a\)。
- 原回答：\(-6/25\)。
- 类型：`Arithmetic Error`。
- 正确部分：象限符号、\(\cos a=-4/5\)、最终负号和分母 \(25\) 均正确。
- 错误位置：分子没有完整计算 \(2\times3\times(-4)\)。
- 当堂订正：重新计算分子得到 \(-24\)，并说明自己刚才误把公式前面的 \(2\)
  当成分母约掉；最终结果为 \(-24/25\)。
- 状态：`Developing`，保留一次轻量算术复测。

## 8. 第二象限特殊角余弦符号

- 触发题：取 \(x=120^\circ\) 验证
  \(1-\cos x=2\sin^2(x/2)\)。
- 原回答：左右两边都等于 \(1/2\)。
- 类型：`Quadrant Sign Error`。
- 正确部分：知道恒等式左右两边应相等。
- 后续思路：能够使用“奇变偶不变，符号看象限”，并正确把余弦变成正弦。
- 错误位置：写成 \(\cos(90^\circ+30^\circ)=\sin30^\circ\)，仍漏掉第二象限的
  负号；正确结构是 \(-\sin30^\circ\)。
- 当堂订正：正确得到 \(1-\cos120^\circ=3/2\)；等待右边独立计算完成后闭环。
- 闭环结果：随后正确算出右边 \(2\sin^260^\circ=3/2\)，确认两边相等。
- 状态：`Developing`，因符号订正需要提示，安排跨日无提示复测。
