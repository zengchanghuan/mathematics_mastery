# 当前错题与待复测队列

更新日期：2026-08-18

## 1. 下界与最小值

- 触发题：\(b_n=2+1/n\)。
- 原回答：把下界 \(2\) 判断为最小值。
- 类型：`Conceptual Error`。
- 订正：所有项都满足 \(b_n>2\)，没有任何一项等于 \(2\)；所以 \(2\) 是下界，但不是最小值。
- 当堂证据：能够正确判断 \(1/n\) 的 \(0\) 是“下界非最小值”。
- 状态：`Developing`，需要跨日无提示复测。

## 2. 保号性的“最终”限定

- 触发结论：\(a_n\to-3\)。
- 原回答：“一直为负”。
- 类型：`Conceptual Precision Error`。
- 订正：只能推出“从某一项开始一直为负”；前面有限项允许为正。
- 例子：\(a_n=-3+10/n\) 的前几项为正，之后为负。
- 状态：`Developing`。

## 3. 夹逼定理中上界与上界的极限

- 触发题：\(\lim |\sin n|/n\)。
- 原回答：\(1\)。
- 类型：`Limit Error`。
- 订正：\(0\le |\sin n|/n\le1/n\)，左右两边都趋近于 \(0\)，所以中间极限为 \(0\)。
- 当堂证据：能够补出
  \(1/n\le(2+\sin n)/n\le3/n\)。
- 状态：`Developing`，需要独立变式复测。

## 4. 运算符抄读

- 触发题：两个收敛数列因子的乘积极限。
- 原回答：把括号间乘号看成加号，得到 \(3\) 而不是乘积结果。
- 类型：`Transcription Error`。
- 订正策略：计算前先圈出最外层运算符，再分别写出每个因子的极限。
- 当堂证据：独立完成下一道乘积极限并得到 \(12\)。
- 状态：保留轻量抽查，不视为概念不会。

## 5. 三角恒等式证明链缺口

- 触发公式：\(1-\cos x=2\sin^2(x/2)\)。
- 表现：公式显得突兀，不能从已有公式自然追溯来源。
- 类型：`Prerequisite Gap`，不是计算错误。
